## Installing

**Android:** open the APK and allow "Install unknown apps" for your browser or file manager when asked.

**Windows:** run the setup. The app isn't code-signed yet, so SmartScreen may show "Windows protected your PC". Choose **More info → Run anyway**.

Each release lists SHA-256 checksums so you can check your download.
